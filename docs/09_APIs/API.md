## Part 1: Internal FastAPI HTTP Endpoints (`server.py`)

The `HiddenDevTools-Engine` local/cloud server exposes three internal HTTP endpoints bound to `0.0.0.0:8000` via Uvicorn (`server.py`).

### 1. Liveness & Readiness Probe
* **Endpoint:** `GET /health`
* **Controller Reference:** [routers/health.py:L13-L22](file:///e:/Vinitt/HiddenDevTools/HiddenDevTools-Engine/routers/health.py#L13-L22)
* **Description:** Health check probe queried by Docker container orchestration, Cloudflare Tunnel health monitors (`cloudflared`), or AWS ALB targets to verify Uvicorn event loop availability.
* **Query Parameters:** None.
* **Request Headers:** Standard HTTP headers.
* **Response Status Codes:** `200 OK`
* **Response Schema (JSON):**
  ```json
  {
    "status": "ok",
    "service": "HiddenDevTools Webhook Server",
    "timestamp": "2026-07-10T12:00:00.123456"
  }
  ```

### 2. Meta Webhook Subscription Challenge Verification
* **Endpoint:** `GET /webhooks/meta`
* **Controller Reference:** [routers/meta_webhook.py:L18-L34](file:///e:/Vinitt/HiddenDevTools/HiddenDevTools-Engine/routers/meta_webhook.py#L18-L34)
* **Description:** Handshake verification endpoint invoked exactly once by Meta Developer Dashboard when configuring `POST /webhooks/meta` subscriptions for `instagram_manage_comments`.
* **Query Parameters:**
  * `hub.mode` (`str`, Required): Must equal `"subscribe"`.
  * `hub.verify_token` (`str`, Required): Evaluated against `config.META_VERIFY_TOKEN` (`"hidden_dev_tools_secret_verify"`).
  * `hub.challenge` (`str`, Required): Random integer string generated by Meta servers (`"1158201444"`).
* **Response Status Codes:**
  * `200 OK`: Verification token matches (`Response(content=challenge, media_type="text/plain")`).
  * `403 Forbidden`: Token mismatch (`HTTPException(status_code=403, detail="Verification token mismatch")`).
* **Curl Verification Example:**
  ```powershell
  curl -i -X GET "http://localhost:8000/webhooks/meta?hub.mode=subscribe&hub.verify_token=hidden_dev_tools_secret_verify&hub.challenge=12345"
  ```
  *Expected Output:* `HTTP/1.1 200 OK` with body `12345`.

### 3. Meta Webhook Event Reception & Background Queueing
* **Endpoint:** `POST /webhooks/meta`
* **Controller Reference:** [routers/meta_webhook.py:L37-L60](file:///e:/Vinitt/HiddenDevTools/HiddenDevTools-Engine/routers/meta_webhook.py#L37-L60)
* **Description:** Primary production reception endpoint for real-time Instagram comments. Receives raw JSON bytes, validates cryptographic signature (`X-Hub-Signature-256`), and delegates processing to `FastAPI.BackgroundTasks` (`meta_service.process_comment_webhook`).
* **Request Headers:**
  * `Content-Type: application/json`
  * `X-Hub-Signature-256: sha256=<hex_digest>` (Required when `config.is_development() == False`).
* **Request Body Schema (Meta Webhook Payload):**
  ```json
  {
    "object": "instagram",
    "entry": [
      {
        "id": "17841400000000000",
        "time": 1720612800,
        "changes": [
          {
            "field": "comments",
            "value": {
              "id": "18347679586170300",
              "from": {
                "id": "3705030049648518",
                "username": "imvinitbruhhhh"
              },
              "media": {
                "id": "18126080746733956"
              },
              "text": "DEV",
              "parent_id": "18347679586170300"
            }
          }
        ]
      }
    ]
  }
  ```
* **Response Status Codes:**
  * `200 OK`: Signature verified (`{"status": "ok"}`). Response time `< 200ms`.
  * `403 Forbidden`: Cryptographic signature invalid (`{"detail": "Invalid signature"}`).

## Part 2: External API Contracts & Third-Party Integrations

### 4. Google Sheets API (`gspread` v4 / `sheet_api.py`)
* **Base Endpoint:** `https://sheets.googleapis.com/v4/spreadsheets/{SPREADSHEET_ID}`
* **Authentication:** Service Account JSON (`config.GOOGLE_SERVICE_ACCOUNT_JSON`) with OAuth scopes `["https://www.googleapis.com/auth/spreadsheets"]`.
* **Primary Operations:**
  * `get_draft_rows(limit=7)`: Reads `Developer Tools` worksheet rows where `Status == "Draft"`.
  * `mark_generating([row])`: Updates `Status` cell to `"Rendering"` prior to rendering.
  * `mark_ready([row], post_name)`: Updates `Status` (`"Published"`), `Generation ID`, `Generated At`, `Instagram Media ID`, and `Instagram Post URL`.

---

### 5. Supabase Storage REST API (`services/storage_service.py`)
* **Base Endpoint:** `https://<SUPABASE_URL>/storage/v1/object/{STORAGE_BUCKET_POSTS}/{remote_path}`
* **Authentication:** Service Role Admin JWT Key (`config.SUPABASE_SERVICE_ROLE_KEY`) passed inside `Authorization: Bearer <KEY>`.
* **Primary Operations:**
  * `_upload_single(local_path, remote_path)`: HTTP POST binary file upload (`max_workers=3`). Headers: `Content-Type: image/png`, `cacheControl: 3600`, `x-upsert: true`.
  * `verify_url(url)`: HTTP `HEAD` / `GET` check verifying public CDN reachability prior to calling Graph API.

---

### 6. Meta Graph API v23.0 (`services/instagram_service.py`)
* **Base Endpoint:** `https://graph.facebook.com/v23.0`
* **Authentication:** Facebook Page / Instagram Business OAuth Access Token (`config.INSTAGRAM_ACCESS_TOKEN`).
* **Primary Operations & Endpoints:**
  * `create_media_container`: `POST /{INSTAGRAM_BUSINESS_ACCOUNT_ID}/media` (`image_url: str`, `is_carousel_item: true`).
  * `wait_for_container`: `GET /{container_id}?fields=status_code` (polls until `FINISHED`).
  * `create_carousel`: `POST /{INSTAGRAM_BUSINESS_ACCOUNT_ID}/media` (`media_type="CAROUSEL"`, `children="id1..id9"`, `caption=...`).
  * `publish`: `POST /{INSTAGRAM_BUSINESS_ACCOUNT_ID}/media_publish(creation_id)`.
  * `send_message`: `POST /{FACEBOOK_PAGE_ID}/messages` (`{"recipient": {"id": "user_id"}, "message": {"text": "..."}}`).
